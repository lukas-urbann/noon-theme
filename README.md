# Red Noon

A color theme with red accents and calm, high-contrast syntax colors. Beautiful, simple and easy on the eyes.

- **Red Noon**: dark, with softly tinted neutral-grey backgrounds.
- **Red Noon Light**: dampened light greys, never pure white.

## A note about AI

I'm sorry to say that AI was used to make this. This is my own personal VS Code theme, which I made about 6 years ago and wanted to revive. I used AI to rebuild and polish it, and I'm uploading it to the Marketplace for myself and my friends. If AI-assisted work isn't your thing, I completely understand.

## Recommended setup

Red Noon pairs well with the Material look:

- [Material Icon Theme](https://marketplace.visualstudio.com/items?itemName=PKief.material-icon-theme) for file and folder icons
- [Material Product Icons](https://marketplace.visualstudio.com/items?itemName=PKief.material-product-icons) for the icons in the VS Code interface

## Install

Open the Extensions view, search for **Red Noon**, install it, then open **Preferences: Color Theme** and pick **Red Noon** or **Red Noon Light**.

## Other editors

Builds for other editors live in `output/` in the [repository](https://github.com/lukas-urbann/noon-theme):

- `zed/red-noon.json`: Zed. Copy it to `~/.config/zed/themes/`, or install the Zed extension from the `zed/` folder.
- `visual-studio/`: Visual Studio. Import `RedNoon-Dark.vssettings` or `RedNoon-Light.vssettings` through Tools > Import and Export Settings for editor colors. `RedNoon.vstheme` holds the shell colors for the Visual Studio Color Theme Editor.

## Install from source

```bash
npx @vscode/vsce package
code --install-extension red-noon-1.0.1.vsix
```

## Develop

Open this folder in VS Code and press `F5`. A new window opens with the theme loaded, and edits to
`themes/noon-color-theme.json` show up there right away. Run **Developer: Inspect Editor Tokens and Scopes**
to find the scope behind a token.

## Changing colors

The theme files were generated by scripts in `scripts/`, but the current colors were tuned by hand in the theme JSON files. Running `sh scripts/build.sh` regenerates both themes from the palettes in `build_colors.py` and `build_tokens.py`, and overwrites those hand edits.
